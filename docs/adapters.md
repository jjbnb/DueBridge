# 静态平台适配器

应用仅运行经过审阅、编译进同一个 target 的适配器。正式注册包含 BB、智海 MO 和学在浙大；BB 保留 ICS facade，原生网页来源通过 `NativePlatformAdapter` 接入。不会从网络或用户配置下载执行插件。

## 代码入口

| 文件 | 职责 |
| --- | --- |
| `SourceRegistry.swift` | 展示描述、稳定来源 ID、旧运行别名及唯一性校验 |
| `NativePlatformAdapters.swift` | 平台采集、精确请求策略、入口及固定认证脚本配置 |
| `NativeWebSession.swift` | 本机隔离会话、请求执行、账户校验、认证挑战和超时 |
| `NativeTaskCollector.swift` | 有限读取上下文、完整快照与来源账号边界 |
| `SourceTask.swift` / `NativeTaskSync.swift` | 身份、筛选、保留规则及提交计划 |
| `SourceReadGate.swift` | 所有来源共用的读取并发限制 |
| `NativeAppServices.swift` / `NativeSourceViews.swift` | 按注册描述组合生命周期、来源页面与总览 |
| `ReminderDestination.swift` | 与来源无关的目标列表选择、创建和写前校验 |

## 添加一个来源

1. 定义稳定来源 ID、展示名称、任务类型、固定来源域名与兼容别名。展示名可以改，来源 ID 与既有存储/哈希/管理备注标签必须保持稳定。
2. 实现 `NativePlatformAdapter`，提供 `SourceDescriptor`、`NativeAuthenticationConfiguration`、精确请求验证及采集方法。适配器只通过受限读取上下文访问接口，不直接写提醒事项或控制全局调度。
3. 为请求逐项规定 HTTPS、主机、端口、路径、方法、参数和请求体。登录允许的额外主机必须明确列出。正常证书校验由系统处理；固定搜索 POST 需要验证整个请求体，不能仅凭方法认定安全。
4. 证明完整遍历课程和任务分页。缺字段、页码不前进、总数变化、超预算、账号变化或中途失败时，不返回可以提交的部分结果；合法空结果应与登录页或错误响应区分。
5. 以合成 fixture 验证身份稳定、来源/账号隔离、拒绝未知请求、超时取消、空结果、无截止时间和重复同步保留行为。
6. 在静态注册表登记实现和描述，更新源码及测试文件清单和支持文档。校验重复 ID、旧别名冲突、描述与实现不匹配、未知来源均失败关闭。

## 核心约束

核心负责只写明确截止时间、首次往日任务策略、稳定排序、保留完成状态和个人备注。所有来源共享提醒事项写锁及调度入口；每个平台保有独立账号和会话边界。写入前仍需核验账号、请求代次和目标列表，暂停或改选目标后的旧回调不得继续提交。

不得修改旧来源身份以“简化”适配器接入；不得通过通配域名、任意 URL、任意 JavaScript、跳过证书验证或自动接管旧账户来扩展支持范围。

## 第四平台测试的边界

`NativeAdapterTests.swift` 中的第四来源是测试专用契约证明：在不修改核心采集分发、写入或调度分支的情况下，静态登记一个合成适配器并验证隔离。它使用模拟读取，没有真实网站、登录账号或线上集成，也不在正式注册表和用户界面出现。

能通过这项测试不等于新网站已受支持。新增真实平台仍需独立说明接口依据和授权范围，并完成登录、预览、首次导入、重复导入及重开验收后，才可更新 README 支持表。
