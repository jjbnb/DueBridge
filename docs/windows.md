# Windows 版

Windows 11 x64 开发版读取 BB、智海 MO 和学在浙大。预览和独立桌面卡片显示课程、截止时间和倒计时；无需连接 Outlook 即可使用。按需授权个人 Outlook 后，专用日历接收同步后的截止事件，手机使用同一 Microsoft 账户的 Outlook 即可查看。

## 构建与微软授权

在 Windows 安装 .NET 10 SDK 和 Microsoft Edge WebView2 Runtime。在仓库根目录运行合成检查和构建：

```powershell
dotnet run --project Windows/DueBridge.Core.Tests
dotnet run --project Windows/DueBridge.School.Tests
node --test Windows/DueBridge.School.Tests/SchoolBridge.test.cjs
dotnet run --project Windows/DueBridge.Outlook.Tests
dotnet build Windows/DueBridge.Windows
```

部署者在 Microsoft Entra 注册允许个人 Microsoft 账户的公共桌面客户端，在「移动和桌面应用程序」平台配置 `http://localhost` 回调，并配置 Microsoft Graph 的委托权限 `Calendars.ReadWrite`。使用应用程序的公开客户端 ID 构建，登录由系统浏览器完成。 [微软注册说明](https://learn.microsoft.com/en-us/entra/identity-platform/scenario-desktop-app-registration)

```powershell
dotnet publish Windows/DueBridge.Windows -c Release -r win-x64 --self-contained true -p:DueBridgeOutlookClientId=YOUR-PUBLIC-CLIENT-ID -o build/windows
```

打开 `build/windows/DueBridge.exe`，保留目录中的运行文件。构建可先用来检查来源预览。连接 Outlook 需要部署者配置的有效客户端 ID。授权时请选择个人 Microsoft 账户。

## 同步

1. 在 BB 页点击「打开 BB 登录网页」。登录后从 BB 日历复制 Get External Calendar Link，粘贴私人 HTTPS 订阅并读取预览。智海 MO 和学在浙大请先连接浙大校园网，再使用各自的学校窗口登录并返回归期读取预览。
2. 登录 Outlook，确认创建专用日历。核对预览后按来源启用同步。
3. 查看每个来源的上次成功时间。可立即同步或暂停，也可选择随 Windows 登录启动。应用运行期间以北京时间零点为每日检查基准，恢复运行后补查。

BB 订阅、桌面任务快照和 Microsoft 授权缓存由当前 Windows 用户保护。两套学校网页会话使用各自的本机 WebView2 配置。账号密码在相应的学校或微软页面中输入。Outlook 事件保存课程、任务、日期、来源入口和归期的管理标识。

## 桌面卡片

1. 连接来源并读取预览后，点击预览区域右上角「桌面卡片」。三个来源的任务合并显示，按截止时间升序排列，标明课程与来源。过期任务显示逾期时间，不推断已经完成。
2. 需要自动更新时，在每个来源下勾选「每天自动更新此来源的桌面任务」。默认关闭。该开关仅授权本地读取，不授权写入 Outlook；已有 Outlook 来源开关仍只控制日历写入。
3. 拖动卡片顶部移动位置，拖动边缘或右下角调整大小。「置顶」可让卡片显示在其他窗口上方，默认关闭。位置、大小、显示状态与置顶会随当前 Windows 用户的设置保存。
4. 使用卡片时将主窗口最小化，卡片会继续显示。卡片上的「×」只隐藏卡片；关闭主窗口会隐藏到通知区，右键归期图标可退出。按需选择「登录 Windows 时启动」，此前可见的卡片会随应用恢复。

「刷新」只读取已绑定且可连接的来源，不写入 Outlook，也不要求启用自动更新。全局暂停会停止自动读取和 Outlook 写入，手动刷新与倒计时仍可使用。倒计时每分钟更新显示，不会每分钟请求源站。

断网或学校会话失效时保留上次成功任务，卡片底部显示各来源读取时间与更新失败提示，详细原因可悬停查看或在主窗口查看。重新登录并读取预览后恢复；换学校账号时会替换该来源快照并要求重新选择自动更新及日历同步。切换 Outlook 账号只撤销日历写入同意，不清空桌面任务。重启从本机加密快照立即展示，后台只补查需要更新的来源。

卡片是一扇独立窗口；Win＋D 可能将它一起最小化，可从任务栏或主窗口「桌面卡片」恢复。它不使用原生 Win＋W 面板或 Explorer 桌面嵌入。

## 验收

GitHub Windows 检查使用合成数据测试来源、桌面快照/刷新和 Outlook 写入，并在 Windows 运行器验证 DPAPI 保存恢复，再构建 x64 应用。真实学校登录、回跳、会话恢复、Outlook 授权、手机可见性和重启补查需要在真实 Windows 11 与测试账户上分别验收。

桌面卡片实机验收：未配置 Outlook 时读取三个来源并打开卡片；核对课程、排序与倒计时；最小化主窗口，移动/缩放/置顶卡片并重启；断网点击刷新应保留任务并显示失败；恢复校园网或重新登录后可更新。还需在不同缩放比例和移除外接显示器后检查卡片仍可见。右键通知区图标选择退出后应退出应用，不留下卡片或采集任务。

## Microsoft To Do（预览）

读取学校来源后，在「Microsoft To Do」区域点击授权个人账户，确认 Tasks.ReadWrite 待办权限，再点击「创建 / 恢复归期列表」，按来源启用 To Do，最后点击立即更新。无需先连接 Outlook 日历；两种目标各自选择账户、开关并记录成功时间。原来的微软公开应用 ID 可复用，无需注册新编号；若租户策略阻止动态授权，可在该应用的 Graph 委托权限中补充 Tasks.ReadWrite。

任务进入「归期 · 课程 DDL」列表。标题包含课程，详情管理区包含精确的北京时间截止时刻和来源；To Do 的截止日使用北京自然日。重复同步更新原任务，保留完成状态、个人备注、重要程度、用户提醒和子任务。首版不自动开启提醒，不将 To Do 完成状态写回学校或据此隐藏桌面任务。

请求结果不确定时，应用保存加密的待确认记录，先查找远端管理标记再尝试更新；仍查不到时暂停该项重建。「处理待确认创建」仅在实际存在这类记录时显示，必须先在 To Do 核对，再决定是否允许重建。不要仅为重试清除记录，否则可能产生副本。

Windows 实机验收：个人账户授权并同步一个来源，To Do 查看课程和日期；修改个人备注、勾选完成，再次同步确认保留；断网恢复后确认不重复。学校页面先连接浙大校园网。

实机反馈（2026-11-15）：用户反馈本轮测试通过；微软回执出现的乱码对应成功提示。源码已修复回执字符编码，登录及同步逻辑保持原有规则。

## 通知区弹出列表（05 预览）

点击 Windows 通知区的归期图标，即可临时展开按截止时间排序的三平台任务；点击外部收起。若未看到图标，请检查通知区的上箭头。右键图标可打开主窗口、立即更新或退出。临时列表里的刷新仍只读本地任务，菜单立即更新沿用已启用的云端写入设置。

关闭主窗口改为隐藏到通知区，自动读取与同步继续按原开关执行；退出请使用右键菜单或主窗口的「退出」按钮。图标初始化报错时仍按关闭退出。通知区暂不可见时，重新打开同一归期应用会唤回已有主窗口，不会启动第二份同步。登录启动在图标可用时隐藏主窗口。桌面卡片入口仍保留，两种窗口共用同一快照和计时器。

本包包含微软中文登录回执编码修复。原生托盘点击、外部收起、缩放、多显示器和系统注销仍需 Windows 11 实机验收。
