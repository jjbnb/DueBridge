# 常见问题

## MO 登录卡住或无法进入浙大通行证

0.1.1 起，连接 MO 会直接打开平台公开配置中的浙大通行证入口。平台授权完成后发布的 MO 回跳地址使用 HTTP；客户端仅把交互登录主页面上发往 MO 固定回调路径的 GET 回跳升级为 HTTPS，保留原始参数，再由 MO 完成登录。后台任务请求继续使用原来的 HTTPS 读取规则。

登录窗口会显示超时或加载失败提示，可以点击“重新加载登录页”重试。完成学校登录、回到 MO 后，再点击主窗口的“登录完成，读取课程”。若页面仍无法显示，请提供窗口上的简短错误提示；反馈时不要包含地址栏查询参数、订阅、Cookie 或密码。

此修正基于公开登录链路和离线回归验证；同一修复在本机安装版已有通行证登录、回跳及课程和任务预览正常的用户反馈。其他账号和社区版独立身份的首装结果，仍需在自己的 Mac 上确认。

## 无法启用同步

先在目标列表设置中取得「提醒事项」完整访问权限，再明确选择可写列表或创建新列表。MO / 学在浙大不需要先配置 BB。仅有预览不代表已启用同步。

如果列表被删除、移到不可写账户或暂时不可用，应用应停止写入并要求重新处理；不会悄悄换列表。改选目标后，请先核对新旧列表中的任务，避免自己重复导入。

## 学校登录已过期

重新打开该来源的连接窗口，在学校网页完成登录，然后主动读取课程。不要把密码、Cookie 或私人订阅发给维护者。后台读取遇到重新登录、账号变化或未知响应时应停止，而不会尝试无限重试。

## 截止任务没有出现

先检查预览是否包含该任务及明确截止时间。没有截止时间的记录会跳过；首次导入不新增往日任务。检查是否已启用该来源及目标列表是否可写。

课程平台接口可能变化。发生采集或格式错误时，半份结果不会写入；反馈时只附合成复现和脱敏后的最小错误信息。

## 关闭窗口后没有更新

自动检查需要应用保持运行；关闭窗口与退出应用不同，请查看菜单栏图标。登录恢复还需要系统批准登录项和有效的学校会话。睡眠时不保证准点检查，唤醒后再补查；项目不承诺系统级常驻服务或硬实时提醒。

## 构建后系统再次请求权限

本机构建使用 ad hoc 签名，改变构建或位置可能让 macOS 再次确认提醒事项或登录项权限。按系统设置重新授权，并在应用中重新核对目标列表。项目没有经过 Developer ID 签名与公证的分发包，也不提供关闭系统安全保护的办法。

## 已完成状态、备注或源站已提交

手动完成状态与管理区外的个人备注会保留；源站“已提交”不会自动完成提醒事项。源站任务消失也不自动删除本机记录。应用管理区内的标记用于稳定识别，请勿手动改写这些标记。
