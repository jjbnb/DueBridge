# Windows 通知区 DDL 列表

用户已选择「点击任务栏通知区的归期图标，弹出 DDL 列表」。在现有桌面卡片上增加临时弹出模式，复用三来源的快照、排序、倒计时及唯一计时器，点击外部收起，不额外请求学校服务。原桌面卡片与位置设置保留。

通知区菜单提供打开主窗口、立即更新、退出。主窗口关闭时，图标可用则隐藏到后台；图标初始化失败仍采用原有关闭退出，避免应用无法找回。明确退出和系统结束会话时释放图标与网络任务。登录启动可直接隐藏主窗口。弹出位置根据鼠标所在显示器工作区计算，适应任务栏位置及显示缩放。

实现顺序：先验证弹出几何和关闭决策的失败用例；实现通知区与临时卡片；跨平台回归和Windows交叉构建；独立审查；生成按序号区分的第05个预览包。微软回执乱码修复一并包含。Windows实机确认通知区点击、外部收起、隐藏/退出、重启和缩放。

审查修复：使用命名激活事件使第二次启动唤回既有主窗口，避免 Shell 暂不可用时无法找回；系统结束会话直接停止计时器、释放托盘、触发取消，不依赖 WPF Closing。
