# Windows 桌面截止事项卡片

状态：设计待确认；尚未实现或发布。

## 目的与已确认选择

用户希望像 macOS 桌面小组件一样，直接在 Windows 桌面查看课程 DDL。用户已选择「一直显示在桌面上的独立卡片，可拖动并选择置顶」。沿用现有 Windows 11 x64、.NET 10 和 WPF，不增加独立进程或新的学校登录流程。

## 方案选择

- **已选：归期独立桌面卡片。** 复用现有三个来源、课程名称与倒计时规则；可以直接查看本机任务，无需 Outlook 授权。归期运行期间显示。
- Windows 原生小组件：主要展示于 Win＋W 面板，需要额外的打包与提供程序，不能满足用户选择的常驻桌面卡片。
- 借助其他桌面工具：需要额外安装并传递任务数据，增加配置负担。首版采用归期自己的窗口。

## 首版体验

主窗口增加「桌面卡片」入口。卡片采用现有归期的靛蓝与浅色视觉，默认约 360×480 DIP，允许拖动与调整大小，记住位置、大小、显示状态和置顶选项。置顶默认关闭。显示器配置变化后将窗口移回可见工作区。

卡片合并 BB、智海 MO、学在浙大的本地任务，标明来源和课程，按截止日期升序排列，显示任务名、北京时间截止时间与实时倒计时。全天任务继续以日期呈现；已取消任务不显示。过期任务明确标为已到期，不推断已经完成或已提交。

任务较多时滚动查看。顶部提供置顶，底部提供「刷新」和「打开归期」。关闭卡片会保存隐藏状态；重新打开可恢复。最小化主窗口后卡片继续显示，归期完全退出后卡片随之关闭；主窗口的关闭按钮保持现有退出含义。

这是一扇普通的独立 Windows 窗口。首版不接入 Explorer 桌面层，因此 Win＋D 或「显示桌面」可能将其一起隐藏，恢复窗口即可继续查看。

## 数据与同步

现有预览仅在内存中，自动同步同时依赖 Outlook。本次将本地任务读取与 Outlook 写入分开：各来源单独选择是否自动更新桌面卡片，默认关闭；读取一次预览即可展示本地快照，启用自动更新后按北京时间零点检查，启动、唤醒和网络恢复时补查。Outlook 的授权与来源写入同意继续独立生效。

全局暂停将暂停自动读取和 Outlook 写入，卡片保留已有任务并显示暂停状态。手动「刷新」只读取已绑定的来源，不要求开启自动更新，也不代表授权写入 Outlook。新来源仍在主窗口完成连接和首次预览。

本地快照保存课程、任务、截止时间、稳定标识、所属来源及账号绑定和读取时间，不复制原始网页、订阅链接、令牌或原始备注。使用现有当前 Windows 用户 DPAPI 存储。切换来源账号时替换该来源快照，防止旧账号数据混入新账号。升级可读取旧设置，保留现有登录、Outlook 目标和同步同意。

断网、读取失败或登录过期时保留上次成功快照，并显示各来源的最近读取时间和更新失败提示。首次未读取时提示到主窗口连接来源，不显示误导性的「没有任务」。卡片的最近读取与 Outlook 上次写入成功分别记录。

倒计时使用现有分钟级刷新，不在每次计时刷新时请求网络。卡片复用主程序的任务与单个定时器，不启动额外浏览器采集循环。

## 本轮范围

实现桌面卡片、本地加密快照、独立的自动读取开关，以及与现有 Outlook 同步流程的兼容。首版不增加任务完成勾选、学校提交状态、手机专属小组件或原生 Win＋W 提供程序。Mac 现有提醒事项和日历流程保持兼容。

## 验收

- 未配置 Outlook，也能从三个来源读取并在同一卡片查看；课程标注、任务排序、全天日期和倒计时正确。
- 重复读取不增加副本；老师改期后替换任务时间；重启可立即看到加密快照。
- 网络中断或登录过期时保留任务并显示更新状态；恢复后只补查所选来源。
- 来源账号切换、暂停与 Outlook 账号切换不会写入旧目标或混入旧来源快照。
- 卡片可拖动、调整大小、置顶与隐藏；最小化主窗口可继续查看；退出后无残留窗口或采集进程。
- 合成测试覆盖快照隔离与兼容、排序和调度规则；运行现有 Windows 检查并交叉构建。真实窗口、缩放、多显示器、学校登录和 Outlook 写入由 Windows 11 实机验收。

## 实现者决定与交付

默认尺寸、置顶默认关闭、普通独立窗口、无完成勾选是本设计建议的实现选择。实现后提供 Windows 预览包，保留已配置的微软公开客户端 ID；实机验收前不声称 Windows 视觉与交互已通过。

设计已完成一次实现审查，未发现阻止实施的问题；暂停和手动刷新规则已按审查建议明确。
